NALL-E image generation, without an API key

NALL-E now sends image prompts to a public image service directly from the browser, so trying it does not require setting up an OpenAI key.

The image generator uses Pollinations' public image service. Enter a description, choose a shape, and preview the generated image from the NALL-E page.

Because the service is public and third-party, availability and rate limits are controlled by its provider. Prompts are sent to that service, so avoid including sensitive information.
