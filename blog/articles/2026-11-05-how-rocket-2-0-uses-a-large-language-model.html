How Rocket 2.0 uses a large language model

Rocket 2.0 is an LLM-powered chat product: it sends prompts to a third-party large language model to generate replies.

Rocket 2.0 is a browser-based chat experience powered by a large language model (LLM), a type of AI model that generates text in response to prompts.

The public chat uses Pollinations' third-party AI service. RocketGPT has not trained or hosted the underlying model, and the service provider controls its availability and limits.
