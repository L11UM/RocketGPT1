MakingGPT

Explore the MakingGPT project online from any computer with a web browser and internet connection.

MakingGPT is an experimental RocketGPT adapter for Qwen2.5-1.5B-Instruct. The project page and guide are online; the experimental model preview is not hosted and requires a compatible local setup.

Project accessible online · Model preview runs locally

01 / BASE MODEL

Qwen2.5-1.5B-Instruct

MakingGPT is designed to start from an open model with a RocketGPT LoRA adapter. It is not a foundation model trained from scratch.

02 / RUNS LOCALLY

Your device does the work

The preview uses Apple MLX-LM on Apple Silicon. Prompts go to the local model server on your device, not to RocketGPT's public chat provider.

03 / EARLY EXPERIMENT

Small data, honest claims

The included sample dataset and adapter are too small to establish model quality. Treat outputs as experimental and verify anything important.

Take it for a local test drive

Run MakingGPT locally.

The local chat preview is not hosted online, and adapter weights are not included in the repository. You’ll need an Apple Silicon device with a supported MLX-LM environment, Python 3.11 or newer, and several gigabytes of free disk space for the environment and model download.

  1. 01

    Set up the project

    Clone the repository, then create the Python environment.

    git clone https://github.com/L11UM/RocketGPT1.git
cd RocketGPT1/MakingGPT
python3.11 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
  2. 02

    Prepare data and train an adapter

    The included examples are format samples only. Replace them with original, reviewed data—at least 200 training examples and 20 independent examples each for validation and testing—then validate and train.

    python scripts/validate_data.py
TRAIN_ITERS=100 sh scripts/train_adapter.sh
  3. 03

    Start your local preview

    After training creates an adapter, start the local model and browser preview. The first model load downloads the base model.

    sh scripts/start_local_demo.sh
  4. 04

    Open the address printed in your terminal

    Prompts stay on your device. When you’re done, press Ctrl+C in that terminal to stop the local preview and model server.

Keep expectations grounded. MakingGPT is not GPT-3, and it does not power Rocket 2.0. The public Rocket 2.0 chat remains a separate product using a third-party model through Pollinations.
