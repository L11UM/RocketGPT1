MakingGPT

Explore the MakingGPT project online from any computer with a web browser and internet connection.

MakingGPT is an independent experiment inspired by InstructGPT's broad three-stage approach: supervised fine-tuning, human-ranked answers to train a reward model, and PPO reinforcement learning. It uses Qwen2.5-1.5B-Instruct; no trained model is hosted, and this is not an exact reproduction of InstructGPT.

Project accessible online · Model preview runs locally

01 / SUPERVISED FINE-TUNING

Start with demonstrations

Train the base model on reviewed examples of instructions paired with helpful answers.

02 / HUMAN PREFERENCES

Learn from rankings

People compare two answers to the same prompt. A reward model learns which answer is preferred.

03 / PPO ALIGNMENT

Optimize with guardrails

PPO tunes the SFT model toward the reward signal while a reference-model penalty helps limit drift. Training needs real preference data and a high-memory GPU.

Take it for a local test drive

Explore the local experiments.

The existing chat preview runs a locally trained MLX adapter and is not hosted online. The separate SFT/reward/PPO workflow uses Transformers and TRL, requires substantial GPU memory, and saves checkpoints locally. No trained model is included or hosted.

  1. 01

    Set up the project

    Clone the repository, then create the Python environment.

    git clone https://github.com/L11UM/RocketGPT1.git
cd RocketGPT1/MakingGPT
python3.11 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
  2. 02

    Prepare data and train an adapter

    The included examples are format samples only. Replace them with original, reviewed data—at least 200 training examples and 20 independent examples each for validation and testing—then validate and train.

    python scripts/validate_data.py
TRAIN_ITERS=100 sh scripts/train_adapter.sh
  3. 03

    Start your local preview

    After training creates an adapter, start the local model and browser preview. The first model load downloads the base model.

    sh scripts/start_local_demo.sh
  4. 04

    Open the address printed in your terminal

    Prompts stay on your device. When you’re done, press Ctrl+C in that terminal to stop the local preview and model server.

  5. 05

    Train with human feedback

    Use the separate Transformers/TRL environment and independently reviewed prompt rankings. The preference split files are documented in the project guide; no synthetic rankings are bundled.

    python3.11 -m venv .venv-rlhf
source .venv-rlhf/bin/activate
python -m pip install -r requirements-rlhf.txt
python scripts/validate_data.py
python scripts/validate_preferences.py
python scripts/train_sft_rlhf.py
python scripts/train_reward_model.py
python scripts/evaluate_reward_model.py
python scripts/train_ppo.py
python scripts/generate_rlhf.py --prompt "Explain photosynthesis in one sentence."

Keep expectations grounded. This is an independent, small-scale workflow inspired by InstructGPT's broad training stages, not an exact reproduction. The included examples are only format samples; the preference dataset and trained checkpoints are not included. MakingGPT is not GPT-3, does not power Rocket 2.0, and has not been shown to follow instructions better than Rocket 2.0. That requires a fair evaluation on held-out prompts. Rocket 2.0 remains a separate product using a third-party model through Pollinations.
